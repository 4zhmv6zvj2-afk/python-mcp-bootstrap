# python-mcp-bootstrap v0.2.1

A version bump for the release-check work that already landed on `main`.

## Contents

- The only change in the package is `__version__` in
  `src/python_mcp_bootstrap/__init__.py`, now `0.2.1`. Runtime behaviour is
  unchanged, and the Python floor, the CI lines, and the provisioning pin are
  the same as in `0.2.0`.
- This version number carries the release-check and version-policy changes that
  are already on `main`:
  - `publish.yml` runs `scripts/release_check.py` on the `dist/` directory it
    is about to publish, instead of running its own checksum command. The
    checker owns the required asset names and that directory's checksum.
  - The GitHub release asset check still skips when `gh` is missing or the
    release is not readable yet. Signature and provenance verification stay in
    the workflow.
  - The checker and the version-policy tests read the package floor and the
    product pin from `core.py`. Expected CI lines are the continuous minor run
    from the floor through the pin's minor; a floor patch other than zero is
    rejected, and `requires-python` stays `>=` plus major and minor.

## Release integrity

- This cut is a version bump only: it adds no built distributions, no
  `SHA256SUMS`, no signature bundles, and no provenance file, and nothing is
  uploaded to PyPI by this change.
- Building, signing, and attaching assets is the documented draft-first flow in
  `CONTRIBUTING.md`. Signature and provenance checks stay in `publish.yml`;
  `scripts/release_check.py` does not perform them.

## Artifacts

- None are added by this change. A release prepared from this version is
  expected to follow the naming of earlier releases, with `0.2.1` in place of
  the previous version number.
